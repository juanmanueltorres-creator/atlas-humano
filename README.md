# ATLAS HUMANO

**Un planeta, muchas vidas.**

Ensayo visual interactivo sobre geografía, vida, relaciones humanas, ambiente y futuro. Un caleidoscopio de cartografía real enlaza paisajes satelitales con historias, preguntas y estadísticas documentadas.

## Explorar

Abrí `index.html` en un navegador moderno con conexión a Internet. Para publicarlo con GitHub Pages, elegí `main` / `/ (root)` en **Settings → Pages → Build and deployment → Deploy from a branch**.

No se necesita React, servidor ni compilación.

## Contenido y tecnología

- HTML, CSS, JavaScript y Canvas 2D.
- 32 historias organizadas en seis actos.
- Imágenes satelitales de Esri World Imagery y mosaicos de OpenStreetMap.
- Consultas opcionales a Banco Mundial y NASA EONET.
- `data/catalogo.csv` y `data/fuentes.json`: material de referencia de la edición 5.0. La aplicación actual integra el contenido narrativo directamente en `index.html`, por lo que esos archivos **no se consultan automáticamente**.

## Interpretación responsable

- Las coordenadas seleccionadas pueden funcionar como escenarios editoriales: una cifra global **no describe automáticamente** ese lugar.
- Cada indicador debe leerse con su fecha, definición y fuente original.
- La narración es una interpretación artística/editorial, no una inferencia causal de los datos.
- El proyecto es un prototipo cultural y educativo, no una herramienta de decisión oficial.
